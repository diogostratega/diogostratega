
# Diogo Henrique

Desenvolvedor web com experiência na criação e manutenção de sites para clientes reais.

Atualmente estudo JavaScript pelo DevQuest 2.0, aprofundando meus conhecimentos em desenvolvimento front-end. Também trabalho com automações e integrações de inteligência artificial, principalmente em soluções para pequenos negócios.

Meu foco é evoluir em JavaScript, aprender React e TypeScript e conquistar minha primeira oportunidade profissional como desenvolvedor.

### Projetos

**[Petrocerva Gastrobar](https://github.com/diogostratega/site-petrocerva)**

Site desenvolvido para um gastrobar em Paulista, Pernambuco. Sou responsável pela manutenção, atualização da programação semanal e melhorias na experiência de navegação, principalmente em dispositivos móveis.

[Ver site](https://www.petrocerva.com.br/)

**[MagickAI Paradox - Loja TCG](https://github.com/diogostratega/projeto-magickai-paradox)**

Projeto de loja virtual de cartas desenvolvido durante meus estudos. Possui catálogo de produtos, navegação entre páginas e visualização individual das cartas com informações e preços.

[Ver projeto](https://diogostratega.github.io/projeto-magickai-paradox/)

**[Equipe Tech - LoJSync](https://github.com/diogostratega/projeto-equipe-tech)**

Interface interativa desenvolvida para praticar JavaScript e manipulação do DOM. Permite selecionar personagens e alterar dinamicamente imagens, informações e elementos visuais da página.

**[Sacode Recife](https://github.com/diogostratega/Sacode-Recife)**

Landing page responsiva para divulgação de eventos, com programação, informações de ingressos, localização e integração com WhatsApp.

[Ver projeto](https://sacode-recife.vercel.app/)
